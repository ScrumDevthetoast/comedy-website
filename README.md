# Jason at Sunset

Static comedy website with a surfy sunset landing page, editable upcoming shows, and featured clips.

## Edit content

- Update show dates, venues, links, and descriptions in `script.js`.
- Update clip titles and destination links in `script.js`.
- Update the `instagramPosts` array in `script.js` with your real reel URLs.
- Replace the booking email in `index.html` if needed.

## Run locally

Open `index.html` in a browser.

## Host it

Upload these files to any static host, including GitHub Pages, Netlify, Vercel static hosting, Cloudflare Pages, or your own web server.
